## 关键改动

### 🚀 视频速度提升（最大改动）
**旧架构**：前端逐帧 seek（12帧）→ 每帧单独调云函数 → 12次冷启动 + 12次网络往返
**新架构**：前端逐帧 seek（8帧）→ 合并一次 `ocrBatch` 调用 → 云函数内4路并发OCR
**预计提速**：12次冷启动 + 网络开销 ≈ 减少 40-60s

### 🖼 追问上传图片
追问输入框旁新增图片按钮，用户选图后上传到云存储，云函数自动OCR识别并追加到 LLM 上下文。

### 📎 补充证据
分析报告页底部新增"补充证据并重新分析"按钮，可追加截图/视频/文本后自动触发重新分析。
